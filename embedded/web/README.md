# @tomodellsheetmusic/sable-call-embedded

An embedded build of [sable-call](https://github.com/tomodellsheetmusic/SableCall), a fork of [element-call](https://github.com/element-hq/element-call) that will one day be stable.

## Installation

```
npm install @tomodellsheetmusic/sable-call-embedded
```
